# Nombre del proyecto
Proyecto Litosfera: Monitoreo de Suelo y Alerta de Sequedad con Arduino y LED en Pin 13

## Descripción
En esta práctica de la materia Desarrollo Sustentable con Automatización, se diseñó e implementó un sistema de monitoreo para la litosfera (capa superficial de suelo) utilizando una tarjeta Arduino y un sensor de suelo. El sistema analiza el estado de una muestra de tierra contenida en un vaso para evaluar sus condiciones térmicas y de humedad. Cuando el sensor detecta que la tierra se encuentra seca o fuera de los parámetros adecuados, el sistema activa automáticamente una alerta visual mediante un diodo LED conectado al Pin 13 para notificar que la tierra requiere riego o atención.

## Objetivos de aprendizaje
* Configurar la lectura de datos analógicos y digitales desde un sensor de suelo insertado en una muestra de tierra (litosfera).
* Implementar lógica condicional (`if / else`) para clasificar el estado de la tierra (húmeda / seca).
* Controlar un diodo LED en el Pin 13 de la placa Arduino como indicador visual de alerta por sequedad.
* Desplegar mensajes y estados del suelo en tiempo real a través del Monitor Serie del IDE de Arduino.
* Analizar la aplicación de la automatización agrícola para el ahorro de agua y la conservación de la litosfera en proyectos sustentables.

## Material y herramientas utilizadas
* **Microcontrolador:** Tarjeta Arduino Uno R3
* **Sensor de Suelo:** Sensor de humedad / humedad-temperatura de suelo (Sonda tipo horquilla FC-28)
* **Indicador Visual:** Diodo LED (conectado al Pin 13 digital)
* **Muestra de Estudio:** Muestra de tierra en vaso (Litosfera)
* **Componentes y Conectividad:** Protoboard, cables Dupont / Jumpers y cable USB de datos
* **Software de Desarrollo:** IDE de Arduino

## Resultados
Durante las pruebas de laboratorio del proyecto Litosfera se obtuvieron los siguientes resultados:

* **Prueba en Tierra Húmeda:** Al insertar las puntas del sensor dentro de la muestra de tierra húmeda, el sistema detectó la presencia de humedad, manteniendo el LED del Pin 13 apagado.
* **Detección de Sequedad y Alerta:** Al retirar el sensor de la muestra o al probar en tierra seca, el circuito detectó inmediatamente la falta de humedad y encendió el LED del Pin 13 como señal de advertencia.
* **Monitoreo en Tiempo Real:** El Monitor Serie desplegó correctamente las lecturas e impresiones de estado ("TIERRA SECA / Se recomienda regar"), demostrando una respuesta instantánea y precisa del prototipo.
